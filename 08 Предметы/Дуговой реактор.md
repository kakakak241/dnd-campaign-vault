# Дуговой реактор

Главный незавершенный проект [[Фауст|Фауста]]: миниатюрное аркано-гальваническое ядро, способное стабильно питать [[DZ-52 «Вольтер»]].

## Что должен дать

- Усиление модели Лазутчика.
- Длительную стабильную работу брони.
- Безопасные перегрузки боевых контуров.
- Технологическую основу для защитных систем городов-крепостей.

## Что уже есть

- Чертежи в защищенном тубусе внутри брони.
- Формулы, поправки, зачеркнутые расчеты.
- Пометки вроде «не повторять в помещении».
- Частичные полевые данные с испытаний «Вольтера».

## Что нужно

- Редкие материалы.
- Данные из зон прорыва нежити.
- Проверка поведения контуров рядом с некротическими аномалиями.
- Способ стабилизировать ядро без превращения брони в ходячую катастрофу.

## Риски

- Реактор может привлечь тех, кто хочет оружие, а не защиту.
- Некротическая энергия может войти в контур питания.
- Успешный прототип может стать слишком ценным, чтобы оставить его одному изобретателю.
