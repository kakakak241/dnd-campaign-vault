# DnD Campaign Vault

Obsidian Vault для D&D-кампании.

Открыть в Obsidian: `Open folder as vault` и выбрать эту папку.

## Главные заметки

- `Старт.md`
- `01 Сессии/Сессии - Индекс.md`
- `02 Персонажи/Персонажи игроков.md`
- `07 Квесты/Квесты - Доска.md`

## Текущий фокус кампании

- Кампания почти полностью основана на `Кодекс замогильного путешественника` / `Crypt Dweller Codex`.
- Падение `Аскора`.
- Орды нежити под властью `Никодемаса`.
- `Темное воспоминание`, `Море душ` и план между планами.
- Личные линии персонажей: `Фауст`, `Сар ван дер Сар`, `Мухомор`.
