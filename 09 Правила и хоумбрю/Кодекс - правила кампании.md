# Кодекс - правила кампании

[[Кодекс замогильного путешественника]] - главный источник дополнительных опций для кампании.

## Решения стола

| Тема | Решение |
| --- | --- |
| Расы из Кодекса | Разрешать только после согласования с мастером и привязки к лору |
| Подклассы из Кодекса | Можно использовать для NPC и как опции для игроков после проверки баланса |
| Death & Beyond | Использовать как основу для последствий смерти, возвращения и травм души |
| Void Taint | Пока лорная угроза; механику включить отдельно, если мастер подтвердит |
| Grafting | Доступно как темная, рискованная и редкая практика |
| Magic Items | Использовать как реликвии, награды, проклятые трофеи и цели квестов |
| Spells | Добавлять через обучение, находки, покровителей или исследование |

## Смерть и возвращение

После событий у [[Замок-крепость Аскор|Аскора]] смерть персонажа не должна ощущаться как простая перезагрузка. Возвращение может оставить:

- метку [[Море душ|Моря душ]];
- сон или воспоминание, которого не было;
- связь с тем, кто убил персонажа;
- временную или постоянную замогильную особенность;
- долг перед силой, которая вернула душу обратно.

## Скверна и графтинг

[[Скверна Пустоты]] и графты должны быть соблазном, а не бесплатным усилением.

Принцип: чем сильнее дар, тем яснее цена.

## Что записывать после сессий

- Любые признаки [[Скверна Пустоты|Скверны Пустоты]].
- Все контакты с [[Море душ|Морем душ]].
- Реликвии из Кодекса и кому они достались.
- Новые заклинания или ритуалы из Кодекса.
- Последствия смерти, воскрешения или изменения тела.
